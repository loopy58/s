# 조각조각 퍼즐 (zogakzogakpuzzle.com)

브라우저에서 바로 하는 직소 퍼즐 웹게임입니다. 설치·서버·외부 라이브러리 없이 정적 파일만으로 돌아가서, 어떤 호스팅에 올려도 그대로 열려요.

![공유 미리보기](icons/og.jpg)

## 무엇을 할 수 있나요

| 기능 | 설명 |
| --- | --- |
| 오늘의 퍼즐 | 날짜로 정해지는 그림이에요. 같은 날엔 모두가 같은 그림, 같은 조각 모양으로 기록을 겨뤄요. |
| 랜덤 그림 | 7가지 테마(노을 산맥, 별빛 마을, 푸른 바다, 꽃 들판, 스테인드글라스, 바우하우스, 열기구 축제)를 코드로 그때그때 그려요. 외부 이미지가 없어서 저작권 걱정이 없고 오프라인에서도 돼요. |
| 내 사진으로 | 갤러리 사진으로 퍼즐을 만들어요. 사진은 기기 밖으로 나가지 않아요. |
| 난이도 | 쉬움 12 · 보통 24 · 어려움 48 · 고수 96 · 달인 150조각 (그림 비율에 맞춰 조금씩 달라져요) |
| 점수 | `조각 수 × 100 × 정확도 보정 × 속도 보정`. 판 위 엉뚱한 자리에 놓으면 실수, 밑그림을 쓰면 −15% |
| 기록 | 난이도별 최고 점수 10개와 최근 퍼즐 (이 브라우저에 저장) |
| 이어하기 | 창을 닫거나 새로고침해도 맞추던 상태 그대로 이어서 해요. |
| 공유 | 완성하면 `?seed=…&level=…` 링크를 공유해서 친구가 똑같은 퍼즐에 도전할 수 있어요. |
| 앱 설치 (PWA) | 홈 화면/바탕화면에 앱처럼 설치되고, 한 번 열어 두면 오프라인에서도 돼요. |

조작은 마우스·터치 모두 됩니다. 조각을 끌어서 제자리 가까이에 놓으면 딸깍 붙어요. 화면 위 버튼은 왼쪽부터 메뉴(일시정지), 미리보기, 밑그림, 조각 다시 흩기예요.

> PC 크롬에서 "앱으로 설치"하면 바탕화면 바로가기는 `chrome_proxy.exe --app-id=…` 를 실행하도록 만들어져요.
> 이건 크롬이 설치한 웹앱을 여는 실행기일 뿐이고, 게임 내용은 이 웹사이트에 있어요.

## 내 컴퓨터에서 실행하기

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭하면 안 열리고, 간단한 웹 서버로 열어야 해요.

```bash
# 저장소 최상위에서
npx serve zogakzogak-puzzle          # http://localhost:3000
# 또는
python3 -m http.server -d zogakzogak-puzzle 8080   # http://localhost:8080
```

## zogakzogakpuzzle.com 에 올리기

이 폴더의 파일을 그대로 웹 서버의 최상위(`/`)에 올리면 끝이에요. 빌드 과정이 없어요.

### 방법 A. GitHub Pages (무료)

이 저장소의 GitHub Pages는 이미 "감염병 원정대"가 쓰고 있어서, 퍼즐은 **새 저장소**로 따로 올리는 게 깔끔해요.

1. GitHub에서 새 저장소(예: `zogakzogak-puzzle`)를 만들고, 이 폴더 **안의 파일들**을 저장소 최상위에 올립니다. (`CNAME` 파일도 함께)
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)`로 저장합니다.
3. 같은 화면의 **Custom domain**에 `zogakzogakpuzzle.com`을 넣고 저장합니다.
4. 도메인을 산 곳(가비아, 후이즈, Cloudflare 등)의 DNS 관리에서 아래 레코드를 추가합니다.

   | 종류 | 이름(호스트) | 값 |
   | --- | --- | --- |
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |
   | CNAME | `www` | `<GitHub 아이디>.github.io` |

5. DNS가 퍼지면(몇 분~최대 하루) Pages 화면에서 **Enforce HTTPS**를 켭니다. 앱 설치(PWA)와 오프라인 기능은 HTTPS에서만 동작해요.

### 방법 B. Cloudflare Pages · Netlify

둘 다 이 폴더를 끌어다 놓기만 하면 배포돼요(Netlify Drop, Cloudflare Pages의 "Direct Upload").
배포한 뒤 각 서비스의 **Custom domains** 메뉴에서 `zogakzogakpuzzle.com`을 연결하고, 안내하는 DNS 레코드를 도메인 업체에 넣으면 됩니다.

### 배포한 뒤 바꿀 때

`sw.js`가 온라인일 때는 항상 새 파일을 먼저 받아서, 파일만 다시 올리면 바로 반영돼요.
파일 목록을 바꿨다면 `sw.js`의 `CACHE` 이름(`zogak-v1` → `zogak-v2`)과 `APP` 목록도 함께 고쳐 주세요.

## 폴더 구조

```
index.html            화면 뼈대 (첫 화면, 퍼즐 판, 기록, 창들)
style.css             디자인 (밝은/어두운 테마, 휴대폰 레이아웃)
js/main.js            화면 흐름: 준비 → 퍼즐 → 완성 → 기록, 점수 계산, 이어하기, 공유
js/game.js            퍼즐 판: 조각 그리기, 끌어 놓기, 맞춤 판정, 흩어 놓기, 완성 연출
js/jigsaw.js          조각 모양(베지어 곡선) 만들기, 난이도
js/art.js             퍼즐 그림 7가지 테마를 seed로 그리기
js/store.js           localStorage 저장 (이어하기·기록·설정)
js/sound.js           Web Audio 효과음
js/rng.js             seed 난수, 해시, 섞기
sw.js                 오프라인용 서비스 워커
manifest.webmanifest  앱 설치 정보
icons/                앱 아이콘, 공유 미리보기 이미지(og.jpg)
CNAME                 GitHub Pages 사용자 도메인
```

## 다음에 해 볼 만한 것

- **전 세계 순위표**: 지금 기록은 각자 브라우저에만 있어요. 오늘의 퍼즐 순위를 모두와 겨루려면 기록을 받아 줄 서버가 필요해요.
  Supabase·Firebase 같은 서비스에 `날짜, 난이도, 닉네임, 시간, 실수, 점수` 표를 만들고, 완성할 때(`js/main.js`의 `onComplete`) 올리면 돼요.
  누구나 점수를 보낼 수 있으니, 서버에서 시간·조각 수로 점수를 다시 계산하고 말이 안 되는 기록(예: 150조각을 10초에)은 걸러 주세요.
- 그림 테마 추가: `js/art.js`의 `THEMES`에 그리는 함수를 하나 더 넣으면 돼요.
- 조각끼리 먼저 붙여서 덩어리로 옮기기, 테두리 조각만 모아 보기 같은 고급 기능
